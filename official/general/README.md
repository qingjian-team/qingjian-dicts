# 青简通用扩展词库

青简从自有语料（262 个已去重的训练分片）里挖出的 2～30 字词，不导入其他输入法的词表。
当前版本 V21（2026-10-29 构建）：1,557,495 条，另有 21,143 条隔离记录不进使用文件。

这是仍在清洗中的完整候选库，部分词形和读音待审核，不是逐条人工审核过的常用词库；
其中机器初筛较好的 247,571 条冻结子集放在 [`../base/cleaned.tsv`](../base/cleaned.tsv)，与基础词库同一档，其余进这本扩展词库、排序低一档。

## 文件

`words/<拼音首字母>.tsv`：`词\t数字声调拼音\t权重`，无表头；1～4 为声调、5 为轻声，ü 写 v。
整份有 51MB，超过 GitHub 的单文件警告线，所以按拼音首字母拆成 23 个文件（zh / ch / sh 分别归在 z / c / s），每个文件内按码点排序。
打包时 `LC_ALL=C sort -m words/*.tsv` 归并回原来的一整份，SHA256 与交付版本 `VERSION.json` 里记的一致
（V21：`844d312bfcedf75c62499632072a1601671356039b4fa2f88c0136a20f1370b5`）。

不带声调与带声调符号的两种写法可以由数字声调版换算，不另放。

## 更新

换新的交付版本：同样按拼音首字母拆开覆盖 `words/`，换上新的 `VERSION.json`，改这份说明里的版本与条数，`dict.toml` 的 `version` 升一号。
基础词库会用全量给已有的词补声调，换版本后基础词库也要重新生成。
