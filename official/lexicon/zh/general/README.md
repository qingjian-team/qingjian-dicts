# 青简通用扩展词库

青简从自有语料（262 个已去重的训练分片）里挖出的 2～30 字词，不导入其他输入法的词表。
当前版本由交付稿 V21（2026-10-29 构建，1,557,495 条，另有 21,143 条隔离记录不进使用文件）整理而来，1,273,159 条。

这是仍在清洗中的候选库，部分词形和读音待审核，不是逐条人工审核过的常用词库；
早先从 V7 里挑出机器初筛较好的 247,571 条并进了基础词库（[`../base/supplement.tsv`](../base/supplement.tsv)），与基础词库同一档；这本扩展词库排序低一档。

## 和交付稿的差别

交付稿的权重是语料里的原始计数，而且有一部分词基础词库已经收了。直接用会和基础词库挂两份、词频尺度也对不上，
随包后整句准确率反而下降。所以交付稿先经 [`tools/general.py`](../../../../tools/general.py) 整理再放进来，规则与输入法仓库 dict-convert 的 `lexicon/general.rs` 一致：

- 基础词库（`words.tsv` 与 `supplement.tsv`）已有同词同音（不计声调）的剔掉：V21 剔掉 284,336 条；
- 权重换算成基础词库的词频：在两边共有的词上拟合 ln(词频+1) = 截距 + 斜率·ln(权重+1)（V21：斜率 0.967，截距 1.397）；
- 基础词库有这个词、读音却不同的（V21 有 509 条），换算后再除以 8。

`tools/check.py` 会查这本和基础词库有没有同词同音的条目，有就不让合。

## 文件

`words/<拼音首字母>.tsv`：`词\t数字声调拼音\t词频`，无表头；1～4 为声调、5 为轻声，ü 写 v。
整份超过 GitHub 的单文件警告线，所以按拼音首字母拆成 23 个文件（zh / ch / sh 分别归在 z / c / s），每个文件内按码点排序。
`LC_ALL=C sort -m words/*.tsv` 归并回一整份的 SHA256：`d804b1051059e5af2c2e6cd90f88e909cbd5f8b6a7759de338b2875cdcb07aa8`（整理后的，不是交付稿的）。

不带声调与带声调符号的两种写法可以由数字声调版换算，不另放。

## 更新

换新的交付版本：`python3 tools/general.py <交付稿>`（一整份 TSV 或按首字母拆开的目录都行），它会重写 `words/`；
改这份说明里的版本、条数、剔掉的条数、拟合参数与归并后的 SHA256，`dict.toml` 的 `version` 升一号。
基础词库会用交付稿全量给已有的词补声调，所以重新生成基础词库时用的是交付稿，不是这里整理过的文件（见 [`../base/BUILD.md`](../base/BUILD.md) 第 4f 步）。
基础词库换了版本，这里也要用交付稿重跑一遍 `tools/general.py`，再升版本。
V21 交付稿原样存在提交 `e38b224` 的 `words/` 里（`git show e38b224:official/lexicon/zh/general/words/a.tsv`），重跑时取出来当输入。
